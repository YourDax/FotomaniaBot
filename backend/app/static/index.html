Быстрый старт

  1. Импортируйте таблицу школы с контактами КР и РК.
  2. Создайте рассылку: текст для КР и текст для РК.
  3. В заданиях подготовьте черновик в MAX и отправьте сообщение вручную.
  4. Сохраните результат и при необходимости добавьте примечание.

Данные и приватность

            
    
              
  • База данных, журналы и снимки страниц MAX остаются на этом компьютере.
    • 
              
  • В журнал пишутся только служебные операции; содержимое сообщений и телефоны не дублируются.
    • 
              
  • Перед массовой рассылкой проверяйте текст в карточке задания — он уже подставлен с ФИО получателя.
    • 
              
  • Экспорт CSV безопасен для Excel: значения экранируются, файл открывается в UTF-8.
